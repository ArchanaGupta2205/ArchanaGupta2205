## 🚀 Featured Projects

### 🤖 1. Student Assistance — Agentic AI with LangGraph

An AI-powered student assistant that intelligently routes queries to different workflows and provides context-aware responses using document-based RAG.

**Tech Stack:** React, Node.js, Express.js, MongoDB, LangGraph.js, Google Gemini API.

**Key Features**
- Conditional routing for Academic, Fee, and General queries.
- PDF document processing and text chunking.
- Gemini embeddings and vector storage.
- Semantic retrieval using cosine similarity.
- Context-grounded responses using retrieved document content.
- Separate workflows for different query categories.

**Repository:** [Student Assistance — Agentic AI](https://github.com/ArchanaGupta2205/student-assistence-agentic-ai-with-langraph-conditional-workflow-)
